# Mini manual de marca HEXT

## 1. Definicion institucional

HEXT es una plataforma institucional de coordinacion clinica y operacion asistencial.
Su identidad visual y verbal esta centrada en:

- orden
- control
- continuidad del cuidado
- claridad
- confianza
- operacion clinica

HEXT no reemplaza la marca de la IPS. Funciona como identidad de sistema interno o plataforma operativa compatible con la identidad corporativa de cada institucion.

## 2. Posicionamiento

Frase madre:

HEXT sostiene y ordena la operacion del cuidado.

Version corta:

Plataforma de coordinacion clinica y operacion asistencial.

## 3. Personalidad de marca

HEXT debe sentirse:

- institucional
- precisa
- serena
- moderna
- sobria
- operativa

HEXT no debe sentirse:

- publicitaria
- juvenil
- emocional
- juguetona
- startup tech exagerada

## 4. Naming y logotipo

### 4.1 Escritura de marca

Usar siempre HEXT en mayusculas para:

- logo
- navegacion principal
- encabezados de producto
- login
- piezas visuales institucionales

Usos secundarios:

- Hext: permitido solo en texto editorial cuando se requiera un tono mas natural
- hext: reservado para nombres tecnicos (rutas, variables, paquetes, repositorio)

### 4.2 Lineamientos de logo

- Isotipo principal: H solida
- Geometria compacta
- Nodo o cruce clinico implicito
- Sin recursos decorativos
- Evitar simbolos medicos obvios (corazon, estetoscopio, etc.)

## 5. Sistema de color institucional

Color institucional principal:

- Verde HEXT: #17726D

Paleta base:

- Primario: #17726D
- Primario oscuro: #0F5C58
- Fondo suave: #E8F3F1
- Texto principal: #1F2937
- Texto secundario: #6B7280
- Borde/divisor: #D9E2E7
- Blanco base: #FFFFFF

Regla de uso:

- El verde es la identidad institucional.
- Colores como azul, ambar o violeta se usan para estados semanticos clinicos, no como color de marca.

## 6. Tipografia institucional

Tipografia recomendada para software:

- Principal: Inter
- Alternativa: Manrope

Criterios:

- alta legibilidad
- tono digital contemporaneo
- sobriedad y estabilidad visual

## 7. Lenguaje de interfaz (UI)

HEXT debe verse como herramienta de trabajo clinico-operacional.

Principios:

- fondos limpios
- jerarquia visual clara
- tarjetas sobrias
- bordes suaves
- pocos colores activos por pantalla
- estados semanticos controlados
- iconografia simple
- sin elementos ornamentales innecesarios

Promesa visual:

Aqui todo esta bajo control.

## 8. Lenguaje verbal

Tono institucional:

- claro
- directo
- tecnico
- calmado
- util

Ejemplos recomendados:

- Paciente en valoracion
- Agenda del dia
- Cobertura insuficiente
- Responsable asignado
- Pendiente decision clinica

Evitar copys coloquiales de consumo:

- Genial
- Todo listo
- Vamos alla
- Hola
- Que bueno verte

## 9. Recursos graficos

Priorizar:

- grillas
- modulos
- bloques
- nodos
- continuidad
- estructura

Evitar:

- ilustraciones emocionales
- curvas juguetonas
- caritas
- colores pop
- iconos genericos de bienestar

## 10. Traduccion a sistema UI

### 10.1 Tokens base sugeridos

- color.brand.primary = #17726D
- color.brand.primaryDark = #0F5C58
- color.surface.soft = #E8F3F1
- color.text.primary = #1F2937
- color.text.secondary = #6B7280
- color.border.default = #D9E2E7
- color.surface.base = #FFFFFF

### 10.2 Botones

- Primario: fondo #17726D, texto blanco, hover #0F5C58
- Secundario: fondo blanco, borde #D9E2E7, texto #1F2937
- Destructivo: usar color semantico de error, nunca reemplazar color de marca

### 10.3 Cards

- Fondo blanco o #E8F3F1 segun jerarquia
- Borde sutil #D9E2E7
- Radio discreto
- Elevacion minima

### 10.4 Estados semanticos

- Exito, alerta, error e informacion deben diferenciarse del verde institucional
- Mantener contraste y legibilidad
- Usar icono + texto breve + accion cuando aplique

## 11. Reglas de consistencia

- Mantener HEXT en mayusculas como forma canonica de marca.
- Evitar variantes cromaticas no aprobadas para elementos de marca.
- No mezclar tono institucional con microcopy emocional.
- Priorizar continuidad visual entre modulos clinicos, operativos y administrativos.

## 12. Definicion final

HEXT = sistema, estructura y coordinacion del cuidado.
